## Коротко: что такое выделенный IP

**Выделенный IP** — это адрес, закреплённый за одним пользователем: пока действует тариф, выход в сеть идёт с одного и того же адреса, и больше им никто не пользуется. **Общий IP**, наоборот, делят между собой многие клиенты сервиса, поэтому сайт видит на одном адресе трафик сразу нескольких людей.

Если вам нужен просто другой регион, берите общий IP. Если адрес должен быть известен заранее и не меняться, например для белого списка, берите выделенный.

## Чем они отличаются по существу

Вся разница сводится к одному вопросу: делите вы адрес с другими или нет. Остальные свойства (постоянство, пригодность для белого списка, влияние чужого трафика) вытекают из ответа на него.

| Критерий | Общий IP | Выделенный IP |
|---|---|---|
| Кто пользуется адресом | Многие клиенты одновременно | Только вы |
| Постоянство | Адрес может отличаться от подключения к подключению и между узлами | Не меняется, пока действует тариф |
| Белый список IP | Не подходит: адрес не принадлежит вам одному | Подходит, если сервис принимает такой адрес |
| Влияние соседей | Чужие действия могут сказаться на отношении сайтов к адресу | Соседей по адресу нет |
| Как покупается | Для повседневной смены региона | По регионам, с выбором типа сети |

## Где выделенный IP действительно нужен

Выделенный IP оправдан там, где важен сам адрес: его нужно сообщить заранее или смена адреса вызывает лишние проверки. Решение везде принимает сервис на другой стороне, и каждый сервис определяет свою политику сам.

- **Белые списки IP.** SSH-доступ к серверу, админка, база данных, внутренний API или API партнёра, который принимает запросы только с согласованных адресов. С общим IP такой список бесполезен: завтра адрес может оказаться другим.
- **Отдельные профили браузера.** Когда за каждым рабочим аккаунтом закреплён свой профиль браузера, удобно закрепить за ним и свой адрес, чтобы сервис всегда видел вход из одной точки.
- **Тестирование API и интеграций.** Стенду, CI-задаче или партнёру нужен адрес, который достаточно внести в конфигурацию один раз.
- **Предсказуемая репутация.** На общем адресе из-за действий одного клиента проверки могут коснуться всех остальных. На выделенном такого соседского эффекта нет.

## Когда хватит общего IP

Общего IP достаточно, пока вам не нужно, чтобы адрес оставался прежним: это самый простой вариант, с него удобно начинать.

- Вы время от времени открываете сайты и ресурсы другого региона.
- Вы часто меняете регион, и вам безразлично, какой именно адрес достанется.
- Вы хотите сначала попробовать сервис.
- Адрес не нужно никуда вносить и никому сообщать.

## Подводные камни

Выделенный IP не делает вас анонимным и не ускоряет соединение: он меняет только то, какой адрес видят сайты. Скорость и задержка зависят от маршрута и региона, и AnboVPN их не обещает.

- Если пропустить и срок тарифа, и льготный период, адрес освободится, а новый будет другим. Белые списки придётся переписать.
- Один постоянный адрес проще связать с вами, чем общий. Для приватности это минус.
- Метка «выделенный» ничего не гарантирует насчёт доступа: каждый сервис сам решает, кого пускать.

## Как проверить, что адрес именно тот

Подключитесь через нужный IP и спросите у внешнего сервиса, с какого адреса вы выходите. У выделенного IP ответ не должен меняться от запроса к запросу.

```bash
curl https://www.anbovpn.com/ip
```

Повторите запрос после переподключения и на следующий день. Страну, организацию и тип сети покажет бесплатный [инструмент проверки IP](https://www.anbovpn.com/ru/tools/ip-lookup). В белый список вносите только тот адрес, который вы увидели сами.
