## 透明閘道是什麼？把它想成家裡多設的一座「總機」

**透明閘道**（也常稱為旁路由，英文叫 transparent proxy）是區域網路中的一台主機：其他裝置把它當成上網的出口，它再把這些流量轉進 VPN 或代理連線，所以被它帶著走的裝置本身不用安裝任何用戶端。

打個比方：公司裡的每支分機不用各自申請外線，電話統一由總機轉接出去。透明閘道就是你家的那座總機，只是它不取代原本的家用路由器，而是「放在旁邊再多加一台」，「旁路由」說的就是這個位置。你只要告訴裝置「上網請找它」，剩下的事情由那台主機處理。

## 哪些裝置最適合？

最適合的是「裝不了用戶端，但可以修改網路設定」的裝置，一台閘道設好之後，同一個區域網路裡所有指向它的裝置，都會走同一條連線。下面是常見的情境（各平台與服務對連線來源有自己的政策，請依其條款使用）：

- **智慧電視、串流盒、遊戲主機。** 這類裝置通常沒辦法安裝 VPN App，但多半能手動設定閘道與 DNS，很適合用這種方式。
- **NAS 與家用網路。** 想讓 NAS 或家裡其他設備的對外連線統一從同一個地區出去，不用逐台安裝軟體，方便集中管理。
- **遠距工作的家庭辦公室。** 同一個空間裡有好幾台電腦、平板，不想每台都登入、設定一次。
- **開發測試。** 測試用的實體機或虛擬機很多時，改網路設定比逐台安裝用戶端省事。

## 和「每台裝置裝 VPN App」比比看

兩種做法各有適合的場合，不是誰取代誰。下表從幾個日常會在意的角度比較：

| 比較角度 | 每台裝置裝用戶端 | 透明閘道 |
|---|---|---|
| 設定工夫 | 每台都要安裝、登入 | 安裝一次，再逐台改網路設定 |
| 能用的裝置 | 作業系統要有支援的用戶端 | 只要能改閘道與 DNS 就行 |
| 控制的粒度 | 每台可以選哪些 App 走連線 | 指向它的裝置，全部流量都走 |
| 要多維護的東西 | 沒有 | 一台必須常開的 Linux 主機 |
| 出問題時 | 只影響那一台 | 指向它的裝置都會失去出口，要改回原本設定 |

如果你只是想在一台電腦上「挑 App 走連線」，安泊 VPN 用戶端的應用級智慧分流與 TUN 模式就能做到，不需要閘道。閘道是留給那些裝不了用戶端的裝置。

## 動手設定：五個步驟，每一步為什麼要這樣做

安裝透明閘道的流程，是先準備一台常開的 Debian 或 Ubuntu Linux 主機，用一行指令安裝，再把要走這條連線的裝置指向它。以下內容已於 2026 年 11 月對照官方網站查證。

1. **先選方案和地區。** 一台閘道只走一個地區，也就是你購買的那個，所以要先想清楚。到 [透明閘道頁面](https://www.anbovpn.com/zh-Hant/gateway) 看目前有哪些方案。
2. **準備主機，並給它固定的區域網路位址。** 系統需為 Debian 或 Ubuntu（amd64 或 arm64），迷你主機、軟路由、閒置的電腦或伺服器都可以。位址要固定，是因為其他裝置會指向這個位址，它一變，裝置就找不到出口了。
3. **用 root 身分執行安裝指令。** 在你的帳號裡複製方案對應的那一行指令，貼到主機上執行。因為沒有路由器韌體或 App，安裝動作只會發生在這台 Linux 主機上。
4. **把裝置指向它。** 在裝置的網路設定裡，把「閘道」和「DNS」都改成這台主機的區域網路位址；也可以到家用路由器的 DHCP 設定裡統一發放（前提是你的路由器允許修改）。閘道是被動的，沒被指向的裝置不會自動走過它；DNS 也要一起改，網域查詢才不會繞回原本的路徑。
5. **驗證有沒有生效。** 在裝置上用 `curl https://www.anbovpn.com/ip`，或打開免費的 [IP 查詢工具](https://www.anbovpn.com/zh-Hant/tools/ip-lookup)，確認看到的位址和所在地是不是你購買的那個地區。

小提醒：第一次設定時，建議先拿一台裝置測試，確認沒問題再套用到其他裝置，萬一設錯了，影響的範圍也比較小。

## 注意事項：這五件事要先知道

透明閘道有幾項明確的限制：整台只走一個地區、主機必須常開、指向它的裝置全部流量都會經過它、你得自己維護，而且我們不承諾速度、延遲或可用率。

- **一個地區。** 所有指向閘道的裝置，都從同一個地區出去，沒辦法逐台切換。
- **主機要常開。** 主機一關機或斷線，指向它的裝置就沒有出口，需要把設定改回原本的樣子。
- **全部流量都走。** 指向閘道的裝置沒辦法只挑部分 App，想要這種控制請改用用戶端。
- **自己維護。** 系統更新與區域網路設定都由你負責。
- **不承諾速度。** 實際表現取決於你的網路、主機的效能與地區，我們不承諾速度、延遲或可用率。

還有一個常見誤會：以為閘道裝完就「全家自動生效」。其實它只是準備好出口，每一台要用的裝置，都還得自己指向它。

想知道固定位址在什麼情況值得買，可以看 [固定 IP 和共享 IP 差在哪](/zh-Hant/posts/dedicated-ip-vs-shared-ip/)；如果你只想讓單一工具走固定位址，輕量一點的做法是 [HTTP 代理和 SOCKS5 代理怎麼選](/zh-Hant/posts/http-vs-socks5-proxy/)。
