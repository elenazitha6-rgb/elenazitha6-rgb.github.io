## 什麼是透明閘道（旁路由）？

**透明閘道**是區域網路上的一台機器，其他裝置把它當作通往網際網路的路徑。當它同時把這些流量經由 VPN 或代理連線轉送出去時，就扮演**旁路由**的角色，也稱為透明代理：後方的裝置不需要 VPN 應用程式，因為前面的這台機器已經把事情做好了。

## 透明閘道和安裝 VPN 應用程式有什麼不同？

VPN 應用程式只保護它所執行的那一台裝置。透明閘道則涵蓋所有設定使用它的裝置，不論作業系統為何。代價是你得多維護一台機器。

| | 每台裝置安裝 VPN 應用程式 | 透明閘道 |
|---|---|---|
| 設定方式 | 每台裝置都要安裝並登入 | 安裝一次，再把每台裝置指向它 |
| 適用的裝置 | 作業系統有受到支援的裝置 | 任何允許設定閘道與 DNS 的裝置 |
| 每台裝置的控制 | 每台裝置上的應用層級分流 | 使用它的裝置的所有流量 |
| 你要維護的機器 | 無 | 一台必須保持開機的 Linux 機器 |
| 如果它停止運作 | 只影響那一台裝置 | 指向它的裝置會失去路由，直到你把設定改回來 |

如果你想在單一電腦上選擇哪些應用程式要走這條連線，安泊 VPN 用戶端的應用層級分流與 TUN 模式就能做到。閘道則是為了無法執行用戶端的裝置而準備的。

## 設定安泊 VPN 透明閘道需要什麼？

你需要一份透明閘道方案，以及一台持續開機的 Debian 或 Ubuntu Linux 機器（amd64 或 arm64），例如小型伺服器、軟路由或閒置的電腦。安泊 VPN 閘道以 root 身分執行一行指令即可安裝，沒有路由器韌體，也沒有路由器應用程式。以下內容已於 2026 年 11 月對照安泊 VPN 官網核實。

1. **選擇方案與地區。** 閘道只使用一個地區，也就是你購買的那個，請謹慎挑選。目前販售的內容請見[透明閘道頁面](https://www.anbovpn.com/zh-Hant/gateway)。
2. **準備機器。** 一套在區域網路上使用固定位址的 Debian 或 Ubuntu 系統。
3. **執行安裝指令。** 複製你帳戶中為該方案顯示的一行指令，並以 root 身分在那台機器上執行。
4. **把裝置指向它。** 在裝置上，或在路由器的 DHCP 設定中，把閘道與 DNS 設為該機器的區域網路位址。
5. **驗證。** 用 `curl https://www.anbovpn.com/ip` 或免費的 [IP 查詢工具](https://www.anbovpn.com/zh-Hant/tools/ip-lookup)檢查裝置的公開位址。

## 哪些裝置最能受惠於透明閘道？

無法執行 VPN 用戶端、但允許更改網路設定的裝置，最能受惠，包括智慧電視、遊戲主機與部分媒體播放器。區域網路上任何你指向閘道的裝置，都會得到同樣的連線，所以一次設定就能服務多個人與多台裝置。

## 透明閘道有哪些限制？

透明閘道主要有四點限制：所有指向它的裝置都從同一個地區出去，執行它的機器必須一直開著，這些裝置的全部流量都會經過它，而且需要你自己維護。它也不承諾速度、延遲或可用率。細節如下：

- **只有一個地區。** 所有指向閘道的裝置都從同一個地區連出，無法依裝置切換地區。
- **必須持續開機。** 這台機器必須保持通電並連線。它一關機，指向它的裝置就沒有路由。
- **全有或全無的分流。** 使用閘道的裝置，所有流量都會經過它。若要在單一電腦上依應用程式選擇，請改用用戶端。
- **由你自行維護。** 更新與區域網路設定都由你負責。
- **不承諾速度。** 連線品質取決於你的網路、機器與地區，安泊 VPN 不承諾速度、延遲或可用率。
