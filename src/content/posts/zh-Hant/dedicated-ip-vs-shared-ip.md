## 固定 IP 是什麼？先從「門牌號碼」開始想

**固定 IP** 是只配給你一個人使用、在方案有效期間內不會更換的 IP 位址：網站與伺服器看到的來源永遠是同一個位址，也不會混進其他使用者的行為。在安泊 VPN 裡，固定 IP 依地區購買，是專為長期使用而設計的固定地區與出口位址。

用生活來比喻會更好懂。想像你住在一棟大樓：共享 IP 像大樓共用的總機號碼，很多住戶都從同一個號碼打出去，對方只知道「這通電話來自這棟大樓」；固定 IP 則像你家自己的門牌，對方記住一次，下次就認得你。兩者沒有誰比較高級，差別只在「這個位址是不是只屬於你」。

## 五種常見情境，各自適合哪一種？

簡單講：偶爾切換地區、不在意拿到哪個位址，共享 IP 就夠用；需要讓某個系統「認得」你的位址，或不想位址一直變，才需要固定 IP。下表整理了常見情境，實際費用請以官網流量方案頁為準。

| 你的情境 | 比較適合 | 為什麼 |
|---|---|---|
| 偶爾查資料、看看其他地區的網頁 | 共享 IP | 不需要每次都是同一個位址，從簡單的開始就好 |
| 遠距工作，公司伺服器有設 IP 白名單 | 固定 IP | 白名單要登記一個不會變的位址，管理員放行一次就好 |
| 出差或出國時要登入公司系統 | 固定 IP | 登入位置固定，比較方便；各系統的驗證規則不同，仍以公司規定為準 |
| 跨境網購、經營網路賣場後台 | 固定 IP | 登入位置穩定，管理起來比較省心；各平台對帳號與登入環境有自己的規定，請依平台條款使用 |
| 開發測試，要把測試機加進 API 或資料庫的白名單 | 固定 IP | 位址不變，白名單只需設定一次 |

## 買之前先看：四個常見迷思

固定 IP 解決的是「位址穩定」的問題，它不會讓你變匿名、變快，也不會自動變得更安全。下面這幾點，是新手最常搞混的地方。

- **迷思一：固定 IP 等於匿名。** 固定 IP 只是改變網站看到的位址，你登入的服務還是知道你是誰；而且一個只有你在用的位址，長期下來反而更容易和你連在一起。
- **迷思二：固定 IP 會比較快。** 速度取決於網路路徑與伺服器，跟位址類型關係不大。我們不提供速度或延遲的數字，也不做這類承諾。
- **迷思三：固定 IP 比較安全。** 加密是連線方式決定的，不是位址決定的。固定 IP 的好處是位址穩定，以及不會被「鄰居」的行為影響聲譽。
- **迷思四：共享 IP 就是比較差。** 共享 IP 是為日常切換地區設計的，這類用途它做得很好，只是不適合需要「被登記」的場合。

小提醒：安泊 VPN 的固定 IP 是你連出去時對外呈現的出口位址，不是讓外面連回你家的入口。如果想讓家裡的電視或 NAS 統一走同一條連線，請看 [透明閘道是什麼](/zh-Hant/posts/network-gateway-explained/)。

## 還在猶豫？用三個問題幫自己決定

如果還是拿不定主意，先回答下面三個問題，大多數人看完就有答案了。

1. **有沒有人或系統需要事先登記你的 IP？** 例如公司的伺服器白名單。有的話選固定 IP，因為白名單要的就是一個不變的位址。
2. **你的帳號會不會因為登入位置常常變而反覆要求驗證？** 會的話，固定 IP 能讓登入位置穩定，少一點打擾。
3. **只是偶爾用、想先試試看？** 那就從共享 IP 開始。同一個帳號本來就能放多種類型，之後需要再加購固定 IP 也不遲。
