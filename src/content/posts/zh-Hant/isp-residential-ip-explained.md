## 家寬 IP 是什麼？先把 IP 想成一份「戶籍資料」

**家寬 IP** 指的是登記在網路服務供應商（ISP）一般用戶網路名下、和家庭寬頻連線相關聯的 IP 位址，而不是登記在資料中心或雲端主機業者名下。網站與 IP 資料庫通常是依「這個位址屬於誰的網路」來分類，所以這類位址才會被標成「住宅」或「ISP」。

你可以把 IP 位址想成一份戶籍資料：有人登記在社區大樓裡，有人登記在工業區的倉庫。網站看不到你本人，只能查這份「登記資料」，再決定要用什麼態度對待這個連線。

## 網站怎麼知道一個 IP 是哪種類型？

網站或 IP 資料庫主要是查這個位址所屬的 ASN（自治系統編號，用來標示背後營運這段網路的單位）與機構名稱，再歸類成住宅、ISP、資料中心等類型。下表對照兩種最常被拿來比較的位址。

| 比較項目 | 家寬 IP | 資料中心 IP |
|---|---|---|
| 位址屬於誰 | 一般消費型網路業者 | 主機代管或雲端業者 |
| 資料庫常見標籤 | 「Residential」、「ISP」 | 「Hosting」、「Data Center」 |
| 這段位址上常見的流量 | 一般人的日常連線 | 伺服器、自動化程式、雲端工作 |
| 部分網站的處理方式 | 通常當作一般訪客 | 有些網站會加驗證或限制 |
| 費用 | 通常較高 | 通常較低 |

「有些網站會加驗證」是刻意保守的說法：每個網站的政策不同，也有很多網站對兩種位址一視同仁。

## 住宅 IP 和家寬 IP 是一樣的東西嗎？

這兩個名稱各家業者的用法不一，業界沒有統一的定義。一般來說，「住宅」強調位址來自一般家用連線，「家寬」（ISP）強調位址登記在網路業者名下並長期穩定指派。比價之前，先看懂每家業者怎麼定義自己的說法，才不會拿不同的東西比較。

安泊 VPN 的固定 IP 方案同時提供這兩種網路類型，但實際有哪些類型，要看地區的販售狀況；[固定 IP 與住宅 IP 頁面](https://www.anbovpn.com/zh-Hant/residential-ip) 的方案選擇器只會顯示你查看當下買得到的選項。

## 什麼時候才真的用得到家寬 IP？

多數日常用途其實感覺不出差別，只有少數情境比較有幫助。如果下面都不像你，通常共享 IP 就夠了。

- **開發測試與跨境經營。** 想確認自己的網站、App 或廣告，在當地一般訪客眼中長什麼樣子，用一般家用網路類型的位址去看，比較貼近真實情況。
- **遠距工作、出差或出國使用公司系統。** 有些服務對資料中心的位址範圍會多一道檢查；一個長期固定、看起來像一般連線的位址，用起來比較省事。各系統規則不同，仍以你們公司的規定為準。
- **需要長期穩定使用的帳號。** 同一種類型的位址用上幾個月，遇到意外狀況的機會相對少一些。

想知道什麼情況值得花錢買固定位址，可以看 [固定 IP 和共享 IP 差在哪](/zh-Hant/posts/dedicated-ip-vs-shared-ip/)。

## 動手查查看：四個步驟確認 IP 類型

想知道手上的 IP 是哪種類型，最直接的做法是連上那個 IP，再用查詢工具讀它的機構名稱與使用類型。下面每一步都附了原因，不用死記。

1. **先連線到你要檢查的 IP。** 查詢工具看到的是「現在對外的位址」，沒連線的話，查到的會是你自己家裡的。
2. **開啟免費的 [IP 查詢工具](https://www.anbovpn.com/zh-Hant/tools/ip-lookup)，或在終端機輸入 `curl https://www.anbovpn.com/ip`。** 兩種方式都會回報你目前的對外位址與所在地。
3. **看機構名稱與使用類型。** 機構名稱像主機代管或雲端業者，多半是資料中心 IP；像一般電信或網路業者，則偏向住宅或 ISP 類型。
4. **重要的判斷，用第二個工具再查一次。** 各資料庫的分類與更新速度不同，同一個位址的結果可能不一致。

## 常見迷思：家寬 IP 不能保證什麼

家寬 IP 只改變網站看到的「位址類型」，並不保證能連上任何特定的網站或平台。每個服務都有自己的存取政策，也可能隨時調整，請依各網站的服務條款使用。

- **「用了家寬 IP 就不會被驗證或擋下來。」** 不保證。類型只是網站判斷時的其中一項參考。
- **「我家的 IP 就是家寬 IP，不用另外買。」** 你家的位址是業者配給你的，而 VPN 服務提供的是另一個位址，用途與管理方式都不同。
- **「查詢工具說它是住宅，就一定是住宅。」** 查詢結果是參考，不是證明；資料庫可能落後，也可能彼此矛盾。
