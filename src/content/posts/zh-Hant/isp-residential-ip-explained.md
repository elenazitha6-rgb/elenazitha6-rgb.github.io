## 什麼是家寬 IP？

**家寬 IP** 是屬於網路服務商（ISP）消費者等級網路、並與住宅寬頻連線相關聯的 IP 位址，而不是屬於資料中心或雲端主機。網站與 IP 情報資料庫通常依位址所屬網路的擁有者（也就是 ASN）來分類，所以這類位址會被標示為「住宅」或「ISP」。

## 它和資料中心 IP 有什麼不同？

差別在於網路的擁有者，也因此影響了外部服務如何標示它。資料中心 IP 屬於主機代管或雲端公司，通常由伺服器使用。家寬 IP 則屬於消費者網路服務商，看起來就像一般連線的位址。

| | 家寬 IP | 資料中心 IP |
|---|---|---|
| 網路擁有者 | 消費者網路服務商 | 主機代管或雲端公司 |
| IP 資料庫中常見的標籤 | 「Residential」或「ISP」 | 「Hosting」或「Data center」 |
| 該網段上的典型流量 | 使用一般連線的人 | 伺服器、自動化程式與雲端工作負載 |
| 部分網站如何對待 | 通常視為一般訪客 | 有時會額外檢查或設下限制 |
| 一般費用 | 較高 | 較低 |

「有時會額外檢查」是刻意選擇的說法。每個網站都自行決定政策，許多網站對兩種類型一視同仁。

## 住宅 IP 和家寬 IP 有什麼差別？

各家服務商對這兩個名稱的用法並不相同，所以業界沒有單一的定義。一般而言，「住宅 IP」指的是來自消費者連線的位址，「家寬 IP」則指登記在網路服務商名下、並以穩定方式分配的位址。在比較價格之前，請務必先閱讀各家服務商如何定義自己的用語。

## 什麼時候家寬 IP 會有影響？

當某項服務對待資料中心網段與消費者網段的方式不同，或你希望自己呈現出來的位址看起來像一般連線時，家寬 IP 就有影響。對許多日常任務來說，它完全沒有差別。

- **限制資料中心網段的服務。** 有些網站會對來自主機代管網路的流量增加檢查。
- **從消費者網路進行測試。** 檢查你自己的網站、應用程式或廣告，在另一個地區的一般訪客眼中是什麼樣子。
- **長期、一致的使用。** 類型合適的穩定位址，意味著數月的使用期間內出現的意外更少。

如果以上都不符合你的情況，一般的共享 IP 通常就夠用了。固定位址何時值得花錢，請見[固定 IP 與共享 IP 比較](/zh-Hant/posts/dedicated-ip-vs-shared-ip/)。

## 住宅 IP 能保證連上每個網站嗎？

不能。住宅類型的分類，並不保證能連上任何特定的網站或平台。每個服務都有自己的存取政策，而且可以隨時更改。使用任何 IP 時，都請遵守你所造訪網站的服務條款。
