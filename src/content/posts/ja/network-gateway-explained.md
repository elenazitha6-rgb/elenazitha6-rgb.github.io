## ネットワークゲートウェイ（サイドルーター）とは？

**ネットワークゲートウェイ**は、ローカルネットワーク上のほかの端末が、インターネットへの経路として使うマシンです。そのマシンが通信をVPNやプロキシの接続にも流す場合は、**サイドルーター**、または透過プロキシとして機能します。配下の端末にVPNアプリは必要なく、手前にあるマシンが代わりに処理を行います。

## ネットワークゲートウェイは、VPNアプリを入れる方法とどう違いますか？

VPNアプリが保護するのは、それを動かしている端末1台だけです。ネットワークゲートウェイは、使う設定にした端末すべてを、OSを問わずカバーします。引き換えに、管理するマシンが1台増えます。

| | 端末ごとのVPNアプリ | ネットワークゲートウェイ |
|---|---|---|
| セットアップ | 端末ごとにインストールしてサインイン | 1回インストールし、各端末をそこに向ける |
| 使える端末 | 対応OSの端末 | ゲートウェイとDNSを設定できる端末なら何でも |
| 端末ごとの制御 | 各端末でのアプリ単位のルーティング | ゲートウェイを使う端末の全通信 |
| 管理するマシン | なし | 常時稼働させるLinuxマシン1台 |
| 止まったとき | その端末だけが影響を受ける | 向けている端末は、設定を戻すまで経路を失う |

1台のパソコンで、どのアプリに接続を使わせるかを選びたい場合は、AnboVPNクライアントのアプリ単位のスマートルーティングとTUNモードで行えます。ゲートウェイは、クライアントを動かせない端末のためのものです。

## AnboVPNのネットワークゲートウェイを設定するには、何が必要ですか？

ゲートウェイのプランと、常時稼働させるDebianまたはUbuntuのLinuxマシン（amd64またはarm64）が必要です。小型サーバー、ソフトルーター、使っていないパソコンなどが使えます。AnboVPNのゲートウェイは、rootで実行する1行のコマンドで導入します。ルーター用のファームウェアやアプリはありません。以下の内容は、2026年11月にAnboVPN公式サイトで確認しました。

1. **プランと地域を選びます。** ゲートウェイが使う地域は、購入した1つだけなので、慎重に選んでください。販売中の内容は、[ネットワークゲートウェイのページ](https://www.anbovpn.com/ja/gateway)をご覧ください。
2. **マシンを用意します。** ローカルネットワーク上で固定アドレスを持つ、DebianまたはUbuntuのシステムです。
3. **インストールコマンドを実行します。** アカウントに表示されている、プラン用の1行コマンドをコピーし、そのマシンでrootとして実行します。
4. **端末をゲートウェイに向けます。** 端末側、またはルーターのDHCP設定で、ゲートウェイとDNSをそのマシンのローカルアドレスに設定します。
5. **確認します。** `curl https://www.anbovpn.com/ip` または無料の[IPアドレス検索ツール](https://www.anbovpn.com/ja/tools/ip-lookup)で、端末のグローバルアドレスを確認します。

## ゲートウェイの恩恵が大きい端末は、どれですか？

VPNクライアントは動かせないものの、ネットワーク設定は変更できる端末です。スマートテレビ、ゲーム機、一部のメディアプレーヤーなどが該当します。同じローカルネットワーク上で、ゲートウェイに向けた端末は同じ接続を使えるため、1回の設定で、複数の人や端末をまかなえます。

## ネットワークゲートウェイの制約は何ですか？

ネットワークゲートウェイには主に4つの制約があります。ゲートウェイを指すすべての端末が同じ1つの地域から出ること、動作させるマシンを常時稼働させておく必要があること、それらの端末の通信がすべてゲートウェイ経由になること、そして保守を自分で行うことです。速度・遅延・稼働率の保証もありません。詳細は次のとおりです。

- **地域は1つ。** ゲートウェイに向けたすべての端末が、同じ地域を経由します。端末ごとに地域を切り替えることはできません。
- **常時稼働。** マシンの電源とネットワーク接続を維持する必要があります。電源が切れると、向けている端末は経路を失います。
- **全通信が対象。** ゲートウェイを使う端末の通信は、すべてゲートウェイを通ります。1台のパソコンでアプリごとに選びたい場合は、クライアントを使ってください。
- **メンテナンスは自分で行います。** アップデートやローカルネットワークの設定は、利用者の責任です。
- **速度の保証はありません。** 接続品質は、お使いのネットワーク、マシン、地域によって変わります。AnboVPNは、速度・遅延・稼働率を約束しません。
