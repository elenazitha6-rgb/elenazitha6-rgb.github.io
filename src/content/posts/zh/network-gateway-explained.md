## 透明网关是什么？和旁路由是一回事吗？

**透明网关**是局域网里的一台机器：其他设备把它当作上网的“下一跳”，它再把这些设备的流量统一转到安泊 VPN 的连接上。设备自己感觉不到中间多了一道，所以不用装客户端。在家庭网络里，这种接在主路由旁边的做法，通常就叫**旁路由**。

打个比方：装客户端，是给每个人发一张门票；透明网关，是在大门口设一个检票口，经过这扇门的人自动被带过去。

## 装客户端和用透明网关，到底怎么选？

**能装客户端的电脑和手机，优先用客户端；装不了客户端、又想接入同一个出口的设备，用透明网关。**

| 对比项 | 每台设备装客户端 | 透明网关（旁路由） |
|---|---|---|
| 怎么设置 | 每台设备安装并登录 | 机器上装一次，再让设备指向它 |
| 适用的设备 | 有对应客户端的系统 | 只要能改网关和 DNS 的设备 |
| 控制粒度 | 可以按应用分流，还有 TUN 模式 | 设备的全部流量都走网关 |
| 要不要多维护一台机器 | 不用 | 要，而且要常开 |
| 出问题时 | 只影响这一台设备 | 指向它的设备都会受影响 |
| 能不能切地区 | 在客户端里切换 | 不能，整台只走购买的那个地区 |

如果只是想在一台电脑上让指定的应用走连接，用安泊 VPN 客户端的应用级智能分流或 TUN 模式就够了，不必折腾网关。

## 要准备什么？旁路由、迷你主机都行吗？

**你需要一份透明网关套餐，加一台常开的 Debian 或 Ubuntu Linux 机器（amd64 或 arm64）。** 服务器、软路由、迷你主机、闲置的电脑，只要系统和架构对得上都可以；安泊 VPN 不提供路由器固件，也没有路由器 App。以下信息已于 2026 年 11 月对照官网核对，以官网当前页面为准。

具体清单：

- 一份透明网关套餐，**地区只能选一个**，买了之后不能切换，请想好再买，当前在售的见 [透明网关页面](https://www.anbovpn.com/zh/gateway)。
- 一台能用 root 登录的 Debian / Ubuntu 机器，要一直开着。
- 这台机器在局域网里有固定的内网地址（本文假设是 `192.168.1.50`，你的网段可能不同）。
- 想接入的设备能手动改网关和 DNS。多数电视、游戏主机、电视盒子的网络设置里都有“手动设置 IP”之类的选项。

## 手把手：从装好到电视走网关，一共五步

按下面的顺序做，先拿一台设备试通，确认没问题，再考虑让别的设备也指向网关。

1. **买套餐、选地区。** 想清楚这台网关要对应哪个地区。
2. **给网关机器固定内网地址。** 在主路由里给这台机器做 DHCP 地址保留，或者直接在机器上设静态 IP，保证它的内网地址不会变。
3. **执行安装命令。** 在账户里复制这份套餐对应的一行安装命令，到网关机器上用 root 执行。
4. **让设备指向它。** 以电视为例：进入网络设置，改成手动，填一个同网段里没被占用的 IP 和子网掩码，再把“网关”和“DNS”都填成网关机器的内网地址 `192.168.1.50`。游戏主机、电视盒子的做法类似。
5. **验证。** 设备能上网后，用电脑按同样方式指向网关，运行 `curl https://www.anbovpn.com/ip`，或者打开免费的 [IP 查询工具](https://www.anbovpn.com/zh/tools/ip-lookup)，看显示的地址是不是你购买的那个地区。

想让整个家里的设备都走网关？可以在主路由的 DHCP 设置里，把下发的默认网关和 DNS 改成网关机器的地址。**但这样所有设备都依赖那一台机器，请先确认单台设备已经稳定，再改这一步。**

## 用了之后，这几个坑要提前知道

**透明网关省事，但它换来了几个固定的限制，买之前最好都看一遍：**

- **只有一个地区。** 指向它的所有设备从同一个地区出去，没法按设备分别选。
- **机器必须常开。** 关机或断网时，指向它的设备就没有出路，需要手动改回主路由。
- **网关和 DNS 两项都要指向它。** 别只改其中一项。
- **没法按应用分流。** 设备走了网关，它的全部流量都会过去。
- **要自己维护。** 系统更新、内网设置都由你负责。
- **不承诺速度。** 实际体验取决于你家的网络、网关机器的性能和所选地区，我们不承诺速度、延迟或可用率。

## 哪些人适合用，哪些人不必折腾？

家里有装不了客户端的设备，又愿意多维护一台常开机器的人，适合透明网关。

**适合：**

- 家里的电视、游戏主机、电视盒子需要和电脑走同一个出口。
- 家庭办公室、工作室里有多台设备，想让它们共用一个出口（远程办公、店铺运营场景下便于统一管理）。
- 手头已经有闲置的软路由、迷你主机，不用额外买硬件。

**不适合：**

- 只有一两台电脑和手机：直接装客户端更省事。
- 需要经常切换地区：网关只能一个地区。
- 没有常开的机器，或者不想自己维护。

以上场景只是“适合 / 便于”，各平台的政策由平台自己制定，请遵守各平台的服务条款。
