## 什么是透明网关（旁路由）？

**透明网关**是局域网中的一台机器，其他设备把它当作上网的通路。当它同时把这些流量转发到 VPN 或代理连接时，就相当于**旁路由**，也叫透明代理：它后面的设备不需要安装 VPN 应用，因为前面这台机器已经把事情做了。

## 透明网关和在设备上装 VPN 应用有什么不同？

VPN 应用只保护它所在的那一台设备。透明网关则覆盖所有设置为使用它的设备，不论是什么操作系统。代价是你要多维护一台机器。

| | 每台设备装 VPN 应用 | 透明网关 |
|---|---|---|
| 设置 | 在每台设备上安装并登录 | 安装一次，再让每台设备指向它 |
| 适用的设备 | 操作系统受支持的设备 | 任何允许设置网关和 DNS 的设备 |
| 单设备控制 | 每台设备上的应用级分流 | 使用它的设备的全部流量 |
| 需要维护的机器 | 无 | 一台必须保持开机的 Linux 机器 |
| 停止工作时 | 只影响那一台设备 | 指向它的设备会失去通路，直到你把它们改回来 |

如果你想在单台电脑上选择哪些应用走这条连接，安泊 VPN 客户端的应用级智能分流和 TUN 模式可以做到。透明网关则用于那些无法运行客户端的设备。

## 部署安泊 VPN 透明网关需要什么？

你需要一份透明网关套餐，以及一台保持开机的 Debian 或 Ubuntu Linux 机器（amd64 或 arm64），例如小型服务器、软路由或闲置电脑。安泊 VPN 透明网关以 root 身份运行一行命令即可安装，没有路由器固件，也没有路由器应用。以下信息已于 2026 年 11 月对照安泊 VPN 官网核对。

1. **选择套餐和地区。** 透明网关只使用一个地区，也就是你购买的那个，所以请谨慎选择。在售的内容见[透明网关页面](https://www.anbovpn.com/zh/gateway)。
2. **准备机器。** 一套 Debian 或 Ubuntu 系统，并在局域网中使用固定地址。
3. **运行安装命令。** 复制账户中为你的套餐显示的那一行命令，在这台机器上以 root 身份运行。
4. **让设备指向它。** 在设备上，或者在路由器的 DHCP 设置中，把网关和 DNS 设为这台机器的局域网地址。
5. **验证。** 用 `curl https://www.anbovpn.com/ip` 或免费的 [IP 查询工具](https://www.anbovpn.com/zh/tools/ip-lookup)检查设备的公网地址。

## 哪些设备最适合用透明网关？

无法运行 VPN 客户端、但允许修改网络设置的设备受益最大，包括智能电视、游戏主机和部分媒体播放器。同一局域网中任何指向网关的设备都使用同一条连接，所以一次设置就能服务多个人和多台设备。

## 透明网关有哪些局限？

透明网关很简单，但也有取舍。购买前请先了解这些：

- **只有一个地区。** 所有指向网关的设备都使用同一个地区，不能按设备切换地区。
- **必须一直开着。** 这台机器必须保持通电和联网。关机时，指向它的设备就没有通路。
- **全有或全无的分流。** 使用网关的设备，它的所有流量都会经过网关。如果需要在一台电脑上按应用选择，请改用客户端。
- **需要自己维护。** 系统更新和局域网设置由你负责。
- **不承诺速度。** 连接效果取决于你的网络、那台机器和所选地区，安泊 VPN 不承诺速度、延迟或可用率。
