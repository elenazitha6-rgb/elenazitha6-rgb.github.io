## 固定 IP 是什么意思？和共享 IP 差在哪？

**固定 IP** 是分配给单个用户长期使用的出口地址：在套餐有效期内，你每次连上来看到的都是同一个 IP，不换，也不和别人混用。**共享 IP** 则是同一批节点上许多用户共用的出口地址，换节点、换时间，看到的地址都可能不一样。

一句话概括：**共享 IP 是“随用随换”，固定 IP 是“长期占位”。**

| 对比项 | 共享 IP | 固定 IP |
|---|---|---|
| 谁在用这个地址 | 许多用户同时用 | 只分配给一位用户 |
| 地址会变吗 | 换节点、换时间都可能变 | 套餐有效期内不变 |
| 能做 IP 白名单吗 | 不现实，地址不归你一个人 | 可以，前提是对方系统接受 |
| 别人的行为会连累你吗 | 可能，同一地址上有人被限制，你也受影响 | 不受其他用户影响 |
| 怎么买 | 日常切换地区，随用随换 | 按地区购买，出口地址长期保留 |

## 我该选哪个？按你的使用场景对号入座

**偶尔用、经常换地区，选共享 IP；地址本身要“被认出来”、要长期不变，选固定 IP。** 拿不准就先用共享 IP，等真出现需求再加固定 IP，不会白花钱。

| 你的情况 | 建议 | 原因 |
|---|---|---|
| 日常浏览、查资料，偶尔换个地区 | 共享 IP | 不在乎具体是哪个地址 |
| 跨境电商店铺运营，需要长期稳定的登录地址 | 固定 IP | 登录地点不再来回变，便于管理 |
| 海外社交媒体运营，一个账号对应一个固定地区 | 固定 IP | 每个账号使用固定出口，便于统一维护 |
| 远程办公，要连公司内部系统 | 固定 IP | 让同事或 IT 把你的出口加入 IP 白名单，一次就够 |
| 研发联调，对方服务器只放行指定地址 | 固定 IP | 提供一个不会变的出口给对方放行 |
| 刚接触、只想先试试效果 | 共享 IP | 门槛最低，不满意也不心疼 |

上表只是“适合 / 便于”，不是任何结果的保证。各平台有自己的规则，是否放行、怎么判断都由平台决定，使用时请遵守各平台的服务条款。

## 哪些人其实不用买固定 IP？

如果你只是偶尔看看别的地区的内容，或者每次都想换不同的地区，固定 IP 对你来说就是浪费，共享 IP 完全够用。

下面几种情况，建议先别急着买：

- 每天都要在不同国家之间来回切换：固定 IP 一次只绑定一个地区，不适合。
- 没有任何需要把地址告诉别人的场景，也没有账号对登录地点敏感。
- 指望固定 IP 让你“更快”或“更匿名”：这两件事它都不负责，见下文。

## 固定 IP 到期了会怎样？会不会变？

**套餐有效期内，固定 IP 的地址不会变。** 到期后，系统会给一段宽限期，时长按套餐设定，以购买页和账户里的说明为准：宽限期内续费，可以保留原来的地址；宽限期过了，这个地址就被释放，之后不能保证再买到同一个。

如果你已经把这个地址交给对方做了白名单，**最好在到期前就续费**，别拖到宽限期最后一天，否则地址一旦释放，对方那边就得重新放行。

## 买固定 IP 之前，这几个坑先避开

这一节只讲“它不是什么”，帮你把预期放在合理的位置。

1. **不等于匿名。** 网站看到的是一个只有你在用的地址，长期来看，反而更容易和你本人对应起来。
2. **不等于更快。** 速度取决于网络线路、节点和你自己的网络环境，我们不承诺速度、延迟或可用率。
3. **不等于“不会被限制”。** 各平台自行决定如何对待某个地址，固定 IP 解决的是地址稳定的问题，并不决定平台的态度。
4. **地区要想清楚。** 固定 IP 按地区购买，买了就绑定在这个地区，不像共享 IP 那样随手切换。
5. **留意网络类型。** 有的地区提供住宅 IP 或家宽 IP，想弄清楚它们和机房 IP 的区别，可以读 [家宽 IP 是什么？和机房 IP、住宅 IP 怎么区分](/zh/posts/isp-residential-ip-explained/)。
