## 固定 IP 和共享 IP 有什么区别？

**共享 IP** 是同一台服务器上的许多用户同时使用的地址，所以你访问的网站看到的，是许多人从同一个地址发出的流量。**固定 IP** 只分配给一位用户，地址保持不变，也不会混入别人的行为。下面对比中的其他差异，都源于这一点。

| | 共享 IP | 固定 IP |
|---|---|---|
| 谁在使用这个地址 | 许多用户同时使用 | 一位用户（按行业通行定义） |
| 会变化吗？ | 不同连接和不同服务器之间可能不同 | 在套餐有效期内保持不变 |
| 能用于 IP 白名单吗？ | 不现实，因为地址并非你独有 | 可以，前提是对方服务接受 |
| 其他用户的影响 | 他们的行为可能影响网站对这个地址的处理 | 不受其他用户影响 |
| 典型价格 | 较低 | 较高 |
| 最适合 | 日常浏览、切换地区 | 固定地址、长期使用的账号 |

## 什么情况下应该选共享 IP？

如果你只是偶尔需要以另一个地区的身份访问，又不在意具体用哪个地址，就选共享 IP。它价格更低，也是最简单的起步选择。

- 偶尔从另一个地区浏览、阅读或查资料。
- 经常切换地区，不需要两次使用同一个地址。
- 想先试用服务，再决定是否购买固定地址。
- 不需要把地址加入白名单。

## 固定 IP 什么时候值得买？

当地址本身很重要时，固定 IP 才值得：别的系统需要靠这个地址认出你，或者地址变来变去会带来麻烦。它的价格更高，所以应该用来解决某个具体问题。

- **IP 白名单。** 只接受已批准地址连接的服务器、管理后台、数据库和 API，需要一个不会变化的地址。
- **长期使用的账号。** 有些服务在你的登录位置频繁变化时，会要求额外验证。一个稳定的地址可以减少这类提示。
- **远程办公。** 地址一致，同事或合作方批准一次就可以一劳永逸。
- **可预期的信誉。** 在共享地址上，别的用户的行为可能导致网站对这个地址上的所有人发起验证。固定 IP 消除了这种「邻居效应」。

如果你不确定上面哪一条适用于自己，先从共享 IP 开始就好，以后可以再加固定 IP。

## 固定 IP 会让你匿名或更快吗？

不会。固定 IP 改变的是网站看到的地址。它不会向你登录的服务隐藏你是谁，也不承诺更高的速度、更低的延迟或更好的可用性。请把它当作稳定性工具，而不是隐私或性能升级。

如果你在意速度，网络路径和服务器比 IP 类型更重要。如果你在意匿名，只有你一个人使用的单一地址，长期下来比共享地址更容易与你关联起来。

## 怎么选？一份快速清单

1. 你需要把地址交给别人吗，比如用于白名单？如果是，选固定 IP。
2. 你的账号对登录位置变化反应不好吗？如果是，选固定 IP。
3. 使用是偶尔的、试探性的或短期的吗？如果是，选共享 IP。
4. 不确定？先用共享 IP，等出现具体需求再升级。
