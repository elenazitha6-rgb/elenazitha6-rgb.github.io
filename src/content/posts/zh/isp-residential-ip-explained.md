## 什么是家宽 IP？

**家宽 IP** 是属于网络运营商（ISP）面向个人用户的网络、与家庭宽带连接相关联的 IP 地址，而不是属于数据中心或云主机的地址。网站和 IP 情报数据库通常按地址所属网络的所有者（即 ASN）来分类，所以这类地址会被标记为「住宅」或「ISP」。

## 它和数据中心 IP 有什么不同？

区别在于网络归谁所有，也就决定了外部服务如何标记它。数据中心 IP 属于托管或云服务公司，通常由服务器使用。家宽 IP 属于面向个人用户的网络运营商，看起来就像一条普通上网连接的地址。

| | 家宽 IP | 数据中心 IP |
|---|---|---|
| 网络所有者 | 面向个人用户的网络运营商 | 托管或云服务公司 |
| IP 数据库中的典型标签 | 「住宅」或「ISP」 | 「托管」或「数据中心」 |
| 该地址段上的典型流量 | 使用普通上网连接的人 | 服务器、自动化程序和云上的工作负载 |
| 部分网站如何对待 | 通常视作普通访客 | 有时会附加检查或限制 |
| 典型价格 | 较高 | 较低 |

「有时会附加检查」是刻意选用的措辞。每个网站都有自己的策略，许多网站对两类地址一视同仁。

## 住宅 IP 和家宽 IP 有什么区别？

各服务商对这两个名称的用法并不一致，所以没有统一的行业定义。一般来说，住宅 IP 指向来自个人用户连接的地址，家宽 IP 指向登记在网络运营商名下、并作为稳定分配长期保留的地址。比较价格之前，请先看清每家服务商如何定义自己的术语。

## 家宽 IP 在什么情况下有影响？

当某个服务对数据中心地址段和个人用户地址段区别对待，或者你希望自己出现的地址看起来像一条普通连接时，它才有影响。对许多日常事务来说，两者完全没有区别。

- **限制数据中心地址段的服务。** 有些网站会对来自托管网络的流量增加检查。
- **从个人用户网络做测试。** 查看你自己的网站、应用或广告，在另一个地区的普通访客眼中是什么样子。
- **长期、一致的使用。** 类型合适的稳定地址，意味着几个月的使用中会少一些意外。

如果以上都不符合你的情况，普通的共享 IP 通常就够用了。固定地址什么时候值得付费，请见[固定 IP 与共享 IP 对比](/zh/posts/dedicated-ip-vs-shared-ip/)。

## 住宅 IP 能保证访问所有网站吗？

不能。住宅属性并不保证能访问任何特定的网站或平台。每个服务都有自己的访问策略，并且可以随时调整。使用任何 IP 时，请遵守你所访问网站的服务条款。
