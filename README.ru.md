## Способы подключения: сравнение

| Способ | Как работает | Когда подходит |
|---|---|---|
| **Общий IP** | Переключение между общими узлами в разных регионах | Повседневное использование, частая смена региона |
| **Выделенный IP** | Закреплён за одним пользователем, адрес не меняется в течение срока действия пакета | Белые списки, долгие сессии с одного адреса |
| **HTTP/SOCKS5-прокси** | Отдельный выход для конкретной программы | Одно приложение, скрипт или утилита |
| **Сетевой шлюз** | Один Linux-хост обслуживает все устройства, указавшие на него | ТВ, консоли и другие устройства, куда нельзя поставить клиент |

## Детали и ограничения

**Общий IP**
- Все общие узлы расходуют один баланс трафика, поэтому покупать пакет под каждый регион не нужно.
- Подробнее: [Выделенный и общий IP: как выбрать под свою задачу](https://elenazitha6-rgb.github.io/ru/posts/dedicated-ip-vs-shared-ip/)

**Выделенный IP**
- Адрес не меняется весь срок действия пакета. Выход — резидентный IP или резидентный IP от провайдера (ISP).
- Подробнее: [Резидентный IP от провайдера (ISP) и как проверить тип](https://elenazitha6-rgb.github.io/ru/posts/isp-residential-ip-explained/)

**HTTP/SOCKS5-прокси**
- Один набор учётных данных работает для обоих протоколов; опционально можно ограничить доступ белым списком исходных IP.
- Ограничения: SOCKS5 UDP не поддерживается, порт 25 и доступ во внутренние сети закрыты, включение происходит по узлам, по одному.
- Подробнее: [HTTP- и SOCKS5-прокси: разница на уровне протокола](https://elenazitha6-rgb.github.io/ru/posts/http-vs-socks5-proxy/)

**Сетевой шлюз**
- Устанавливается одной командой от root на Debian или Ubuntu (amd64 / arm64). Прошивки для роутеров нет.
- Ограничения: весь хост выходит через один регион, машина должна работать постоянно.
- Подробнее: [Сетевой шлюз: схема, установка и ограничения](https://elenazitha6-rgb.github.io/ru/posts/network-gateway-explained/)

**Маршруты, оптимизированные для ИИ** — не отдельный продукт, а упаковка выделенного IP или прокси: маршруты под ИИ-сервисы плюс резидентный IP или резидентный IP от провайдера (ISP) на выходе. Что это даёт и чего не обещает — в статье [Маршруты, оптимизированные для ИИ: что это такое](https://elenazitha6-rgb.github.io/ru/posts/ai-optimized-routes-explained/).
